Поле «Ссылка на вакансию HH» и «Заполнить по ссылке» заполняют название, компанию, описание, город, формат, нижнюю границу зарплаты, налоги и навыки. Сохранение/оценка/подготовка письма остаются отдельной кнопкой. Источник включён в описание.

Локальный сервер читает публичную HTML-страницу HH и парсит HH-Lux-InitialState как JSON, без выполнения JavaScript. HTTPS hh.ru /vacancy/ID, ограниченный хост/путь, удаление tracking query, запрет credentials/нестандартных портов/редиректов, timeout 20 s, ограничение 5 MB. Пользовательские данные/токены/cookies не передаются на HH. Зарплата автоматически переносится только при явно подтверждённых RUR/MONTH/from; остальные случаи требуют проверки. Неизвестный/неоднозначный формат не угадывается. Архивные и неполные страницы отклоняются.

19 тестов, TypeScript и сборка прошли. Проверены URL/сбои/размер/страница/налоги/альтернативные условия/Origin/отсутствие автоматической записи. Browser UAT: настоящая ссылка 137302282 заполнила Napoleon IT, полный текст, Петербург, гибрид и 7 навыков; зарплата пустая по объявлению. Ошибочная ссылка example.com показала ошибку и сохранила заполненные поля. Повторная реальная загрузка успешна. Фото: output/hh-link-import.jpg.

Сервер перезапущен с сетевым доступом (сессия 9959), localhost:4310. Первый sandbox-запуск не имел доступа к HH; после разрешённого запуска живой импорт подтверждён. Node fetch публичной страницы возвращает 200. Официальный API detail не ответил за 15 s, поэтому импорт использует публичную страницу, независимо от API.

Ограничения: изменение внутренней разметки HH может потребовать обновления парсера; CAPTCHA/вход не обходятся. Зарплатная ветка покрыта синтетическими тестами, реальная проверенная вакансия без зарплаты. Не поддерживается автоматическая конвертация валют/часовых оплат или определение налогов по догадке. Форма оставлена заполненной для пользователя, карточка не сохранена автоматически.
